CVI - the function that shapes the market, read at four points. At projection the viewer's tier, sub-tier, group and country are checked against each order's rule set: ineligible liquidity is absent, not greyed. Both sides are re-verified at match and at settlement. A watcher pulls a maker's orders the moment status or expiry ends. The three demo identities are real A-Passes, issued via generate_apass at chosen sub-tiers and read live by query_apass; the lapse is a real update_status freeze at the registry.

CVA - both legs. The cash leg is Cleanverse aUSDC itself, 0xaC0893567D43C3E7e6e35a72803df05416C1f20D, which enforces CVI on transfer: a wallet with no A-Pass cannot receive it. The security is a CVA registered via register_atoken under the same identity set, so those who can legally settle are exactly the set the book was projected for.

CCP Protocol - rules come from getRulesV2 on the compliance validator at 0xaC7e5179C2C7f03f209136886c172eb34F161792, OR-evaluated so a listing carries several cohorts. The Cleanverse team confirmed the complete RuleV2 shape: allowedGroup, allowedSubGroup, minTier, minSubTier, isBlackList, countryBitmap. Venue decodes all six fields, including the isBlackList country-direction flag. canTransfer is not on that validator address, so we implement the documented IATokenPolicy and gate against an instance mirroring live CVI sub-tiers, the policy a constructor arg so it repoints with no code change. The matcher eth_calls it at match formation so refusals cost no gas; both tokens call it again while settling, so the matcher is never trusted.

API/SDK - a typed client over the v3 API: query_apass, verify_apass for the registry's own verify link, generate_apass, update_status, register_atoken, download_travel_rule. Retries separate transient sandbox errors from stable business ones; short-TTL cache invalidated on status change.

Beyond the window: settlement is standard EVM against a policy on every integrated network, so Venue runs as-is. Pilot: a transfer agent runs one asset's book for a quarter, replacing email and paper. Chain: Monad.
